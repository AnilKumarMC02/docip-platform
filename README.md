# DOCIP (Driver Operations & Compliance Intelligence Platform)

DOCIP is an internal operations platform designed to help mobility businesses streamline driver onboarding, document verification, support workflows, telecaller operations, and operational decision-making.

## Features

- Driver Search (Mobile Number / Driver ID)
- Driver Intelligence
- Support Workspace
- Health Score Engine
- Priority Queue
- AI Insights
- CSV Upload & Preview
- Summary Cards
- Export Reports

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- PapaParse
